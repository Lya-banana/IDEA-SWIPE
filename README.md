# IDEA SWIPE · 灵感划片

根据 Figma Slides 中的课程概念，制作的可运行交互网页原型。

## 1. 最简单：无需安装

直接用浏览器打开 `index.html`，即可体验**本地演示模式**。输入任意课题会使用本地创意模板给出可判断的卡片；「校园闲置物品交换」含 10 张预制样例卡。它不是真实 AI 输出。

## 2. 接入真实 AI（可选）

需要 Node.js 18 或更高版本，不需要 `npm install`。在终端进入这个文件夹，输入：

```bash
export OPENAI_API_KEY='你的API密钥'
node server.mjs
```

浏览器打开 `http://127.0.0.1:3000`。网页会自动发现可用的服务端，并让聊天输入调用真实模型生成 10 张结构化创意卡。默认模型为 `gpt-4o-mini`，可以设置 `OPENAI_MODEL` 更改；可以设置 `OPENAI_BASE_URL` 接入支持 OpenAI Chat Completions 的兼容服务。

**安全提示：** API 密钥只放在服务器环境变量，网页代码不包含密钥。不要把 `server.mjs` 带着真实密钥公开部署。默认仅监听本机 `127.0.0.1`。

## 3. 交互清单

- 左滑：不喜欢；右滑：有点喜欢；上滑：非常喜欢，可挑选及自定义标签
- 长按卡片或右键：选择并屏蔽标签，阻止之后的创意卡出现该标签
- 支持键盘快捷键：← / → / ↑；二选一阶段可按 `1` / `2`
- 喜爱地图：网格式全局布局、紫色突出非常喜欢、缩放、平移、点击查看、标签筛选及编辑
- 二选一：赢家逐轮对决，完成后得到「最喜欢」的创意
- 数据：浏览器 localStorage 自动保存喜欢记录、屏蔽标签、会话、二选一进度
- 结果：可下载偏好 JSON 或创意概念 Markdown

## 4. 边界

当前为课程交互原型，不是部署到公网的正式 SaaS。AI 后端可选；无 API 密钥或调用失败时自动使用本地样例。偏好记录只保留在本机浏览器同一来源下，清理浏览器数据会清空记录。
